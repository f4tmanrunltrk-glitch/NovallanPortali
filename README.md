# 🚀 NovallanPortali - İlan Portalı

Bu proje, ASP.NET Core MVC kullanılarak geliştirilmiş bir ilan satış/kiralama platformudur.

### ✨ Özellikler:
- **İlan Listeleme:** Modern ve görsel ağırlıklı ilan vitrini.
- **Kategoriler:** Emlak, Vasıta ve Elektronik ilan yönetimi.
- **Teknoloji:** .NET MVC, Entity Framework ve SQL Server.
